\subsection{Simulated Annealing}
\label{subsec:tempera}

% Algoritmo:
% - Sucessor sorteado com sucessor_aleatorio (vizinhança escolhida na
%   Seção~\ref{subsec:busca-local}); aceita se não piora, senão com
%   probabilidade exp(-Delta/T) (distribuição de Gibbs).
% - O que é retornado: a melhor solução vista, não a corrente.
